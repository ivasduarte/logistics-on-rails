# Project Glossary

**Terms, Expressions and Acronyms (TEA) must be organized alphabetically.**


| **_TEA_** (EN)                  | **_TEA_** (PT)                 | **_Description_** (EN)                                                                                                       |  
|:--------------------------------|:-------------------------------|:-----------------------------------------------------------------------------------------------------------------------------|  
| **Aisle**                       | **Corredor**                   | Open space between rows of bays in a warehouse that provides pathways to move goods and access storage bays.                 |  
| **Allocation**                  | **Alocação**                   | Process of assigning concrete quantities of products from specific boxes to satisfy order lines, following FEFO/FIFO rules.  |  
| **Bay**                         | **Baía**                       | A specific storage area within an aisle where boxes of products are stored. Each bay has a limited box capacity.             |  
| **Best Fit Decreasing (BFD)**   | **Melhor Ajuste Decrescente (BFD)** | Packing heuristic that orders allocations by weight (largest to smallest) and places each item in the batch that results in the least unused capacity. |  
| **Bogies**                      | **Bogies**                     | Wheel structure under locomotives and wagons. Used to calculate the weight on the rails (total weight/number of bogies).     |  
| **Box**                         | **Caixa**                      | Storage unit that contains a lot fragment of one SKU with quantity and, optionally, expiry date.                             |  
| **Boxcar**                      | **Vagão Fechado (Boxcar)**     | Type of closed wagon used for transporting general goods.                                                                    |  
| **BoxId**                       | **Identificador da Caixa**     | Unique identifier for each box in the warehouse.                                                                             |  
| **Bridges**                     | **Pontes**                     | Engineering elements that support long-distance freight movement on railway infrastructure.                                  |  
| **Cargo**                       | **Carga**                      | Set of wagons that must be transported from station A to station B.                                                          |  
| **Circulation Lines**           | **Linhas de Circulação**       | Tracks where wagons circulate to reach parking areas or unloading docks.                                                     |  
| **Container Intermodal**        | **Contentor Intermodal**       | Cargo unit. In Europe, 20, 40, and 45 ft containers are common, both regular and high cube.                                  |  
| **Customer Remorse**            | **Remorso do Cliente**         | Return reason where the customer returned the item while still in good condition (e.g., unwanted gift, wrong choice).        |  
| **Cycle Count**                 | **Contagem Cíclica**           | Stock audit where a mismatch was found. Items are not faulty but must be rechecked before restocking.                        |  
| **Damaged**                     | **Danificado**                 | Product that is physically broken or unusable and must be discarded.                                                         |  
| **Diesel Locomotive**           | **Locomotiva Diesel**          | Locomotive powered by diesel fuel.                                                                                           |  
| **Dispatch**                    | **Expedição**                  | Operation that consumes stock from the "front" of the bay list, guaranteeing FEFO/FIFO behavior.                             |  
| **Dock**                        | **Doca**                       | Access point to warehouses where goods are unloaded for longer storage.                                                      |  
| **Domain Model**                | **Modelo de Domínio**          | Conceptual model that represents the shared understanding of the domain among all stakeholders.                              |  
| **Double Track**                | **Linha Dupla**                | Line with two rails where trains can cross without losing speed and without requiring specific facilities.                   |  
| **Electrified Line Segment**    | **Segmento de Linha Eletrificado** | Electrified line segment that allows the circulation of electric locomotives.                                           |  
| **Electric Locomotive**         | **Locomotiva Elétrica**        | Locomotive powered by electricity.                                                                                           |  
| **Endpoint**                    | **Ponto Terminal**             | Stations or terminals that mark the beginning or end of a railway line.                                                     |  
| **Expired**                     | **Expirado**                   | Product that has passed its expiry date and cannot be sold, must be discarded.                                              |  
| **ExpiryDate**                  | **Data de Validade**           | Date until which a perishable product can be safely consumed or sold.                                                       |  
| **FEFO (First-Expired-First-Out)** | **Primeiro a Expirar, Primeiro a Sair (FEFO)** | Inventory management principle where products closest to expiration are dispatched first, minimizing waste.         |  
| **FIFO (First-In-First-Out)**   | **Primeiro a Entrar, Primeiro a Sair (FIFO)** | Stock management discipline where products that entered first are dispatched first, guaranteeing fair rotation.     |  
| **First Fit (FF)**              | **Primeiro Ajuste (FF)**       | Heuristic that places the item in the first available trolley where it fits, following the input order of allocation rows.   |  
| **First Fit Decreasing (FFD)**  | **Primeiro Ajuste Decrescente (FFD)** | Heuristic that orders allocations by weight (largest to smallest) and places the item in the first available batch where it fits. |  
| **Flatcar**                     | **Vagão Plataforma**           | Flat wagon used for transporting containers, vehicles, and machinery.                                                       |  
| **Freight**                     | **Carga Ferroviária**          | Set of wagons that must be transported between stations.                                                                     |  
| **Freight Manager**             | **Gestor de Carga Ferroviária**| Manager responsible for coordinating freight transportation.                                                                 |  
| **Freight Yard**                | **Pátio de Carga**             | Facility for loading, unloading, sorting, and assembling trains.                                                             |  
| **Gauge**                       | **Bitola**                     | Width of the railway track. Important characteristic that some vehicles can support multiple gauges.                          |
