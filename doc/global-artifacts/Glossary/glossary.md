# Project Glossary

**Terms, Expressions and Acronyms (TEA) must be organized alphabetically.**

| **_TEA_** (EN)                                 | **_TEA_** (PT)                                         | **_Description_** (EN)                                                                                                                                                        |  
|:-----------------------------------------------|:-------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|  
| **Aisle**                                      | **Corredor**                                           | Open space between rows of bays in a warehouse that provides pathways to move goods and access storage bays.                                                                  |  
| **Allocation**                                 | **Alocação**                                           | Process used on USEI2 where concrete box quantities are assigned to order lines, following FEFO/FIFO rules.                                                                   |  
| **Bay**                                        | **Baía**                                               | A specific storage area within an aisle where boxes of products are stored. Each bay has a limited box capacity.                                                              |  
| **Best Fit Decreasing (BFD)**                  | **Melhor Ajuste Decrescente (BFD)**                    | Packing heuristic used in USEI3 that orders allocations by weight (largest to smallest) and places each item in the batch that results in the least unused capacity.          |  
| **Bogies**                                     | **Bogies**                                             | Wheel structure under locomotives and wagons. Used to calculate the weight on the rails (total weight/number of bogies).                                                      |  
| **Box**                                        | **Caixa**                                              | Storage unit that contains a lot fragment of one SKU with quantity and, optionally, expiry date.                                                                              |  
| **Boxcar**                                     | **Vagão Fechado (Boxcar)**                             | Enclosed type of wagon used for transporting general goods.                                                                                                                   |  
| **BoxId**                                      | **Identificador da Caixa**                             | Unique identifier for each box in the warehouse.                                                                                                                              |  
| **Bridges**                                    | **Pontes**                                             | Engineering elements that support long-distance freight movement on railway infrastructure.                                                                                   |  
| **Cargo**                                      | **Carga**                                              | Set of wagons that must be transported from station A to station B in a reailway network, managed by a scheduler in USLP7.                                                    |  
| **Circulation Lines**                          | **Linhas de Circulação**                               | Tracks where wagons circulate to reach parking areas or unloading docks.                                                                                                      |  
| **Container Intermodal**                       | **Contentor Intermodal**                               | Cargo unit. In Europe, 20, 40, and 45 ft containers are common, both regular and high cube.                                                                                   |  
| **Customer Remorse**                           | **Remorso do Cliente**                                 | Return reason code in USEI05 where the customer returned the item while still in good condition (e.g., unwanted gift, wrong choice).                                          |  
| **Cycle Count**                                | **Contagem Cíclica**                                   | Stock audit in USEI05 where a mismatch was found. Items are not faulty but must be rechecked before restocking.                                                               |  
| **Damaged**                                    | **Danificado**                                         | Product that is physically broken or unusable and must be discarded in USEI05.                                                                                                |  
| **Diesel Locomotive**                          | **Locomotiva Diesel**                                  | Locomotive powered by diesel fuel. Used in travel calculations in USLP3.                                                                                                      |  
| **Dispatch**                                   | **Expedição**                                          | Operation in USEI01 that consumes stock from the "front" of the bay list, guaranteeing FEFO/FIFO behavior.                                                                    |  
| **Dock**                                       | **Doca**                                               | Access point to warehouses where goods are unloaded for longer storage.                                                                                                       |  
| **Domain Model**                               | **Modelo de Domínio**                                  | Conceptual model created in USLP01 that represents the shared understanding of the domain among all stakeholders.                                                             |  
| **Double Track**                               | **Linha Dupla**                                        | Line with two rails where trains can cross without losing speed and without requiring specific facilities. Affects route scheduling in USLP07.                                |  
| **Electric Locomotive**                        | **Locomotiva Elétrica**                                | Locomotive powered by electricity. Used in travel calculations in USLP3.                                                                                                      |  
| **Electrified Line Segment**                   | **Segmento de Linha Eletrificado**                     | Electrified line segment that allows the circulation of electric locomotives.                                                                                                 |  
| **Endpoint**                                   | **Ponto Terminal**                                     | Stations or terminals that mark the beginning or end of a railway line. Used in USLP03 travel time calculations and USLP07 route planning.                                    |  
| **Expired**                                    | **Expirado**                                           | Product that has passed its expiry date in USEI05 and cannot be sold, must be discarded.                                                                                      |  
| **ExpiryDate**                                 | **Data de Validade**                                   | Date until which a perishable product can be safely consumed or sold.                                                                                                         |  
| **FEFO (First-Expired-First-Out)**             | **Primeiro a Expirar, Primeiro a Sair (FEFO)**         | Inventory management principle used in USEI01, where products closest to expiration are dispatched first, minimizing waste.                                                   |  
| **FIFO (First-In-First-Out)**                  | **Primeiro a Entrar, Primeiro a Sair (FIFO)**          | Stock management discipline used in USEI01, where products that entered first are dispatched first, guaranteeing fair rotation.                                               |  
| **First Fit (FF)**                             | **Primeiro Ajuste (FF)**                               | Heuristic used in USEI3 that places the item in the first available trolley where it fits, following the input order of allocation rows.                                      |  
| **First Fit Decreasing (FFD)**                 | **Primeiro Ajuste Decrescente (FFD)**                  | Heuristic used in USEI3 that orders allocations by weight (largest to smallest) and places the item in the first available batch where it fits.                               |  
| **Flatcar**                                    | **Vagão Plataforma**                                   | Flat wagon used for transporting containers, vehicles, and machinery.                                                                                                         |  
| **Freight**                                    | **Carga Ferroviária**                                  | Set of wagons that must be transported between stations in USLP07 scheduler.                                                                                                  |  
| **Freight Manager**                            | **Gestor de Carga Ferroviária**                        | Manager responsible for coordinating freight transportation and manually defining routes in USLP07 scheduler if the automatic path calculation isn't available.               |  
| **Freight Yard**                               | **Pátio de Carga**                                     | Facility for loading, unloading, sorting, and assembling trains.                                                                                                              |  
| **Gauge**                                      | **Bitola**                                             | Width of the railway track. Important characteristic that some vehicles can support multiple gauges.                                                                          |  
| **High Cube Container**                        | **Contentor High Cube**                                | Container with height greater than standard.                                                                                                                                  |  
| **Hopper Car**                                 | **Vagão Hopper**                                       | Wagon for transporting coal, grains, and minerals.                                                                                                                            |
| **Humidity Sensor**                            | **Sensor de Humidade**                                 | A sensor that measures the humidity of the place in which it is installed.                                                                                                    |
| **Intermodal Transport**                       | **Transporte Intermodal**                              | Combination of rail transport with trucks/ships for "door-to-door" logistics.                                                                                                 |  
| **Inventory**                                  | **Inventário**                                         | Stock of products available in the warehouse, organized by SKU and location.                                                                                                  |  
| **Itinerary**                                  | **Itinerário**                                         | Ordered list of stations through which the train must pass to travel from A to B in USLP07.                                                                                   |
| **Latitude**                                   | **Latitude**                                           | A measure of distance north or south of the Earth's equator, expressed in angular degrees. It is used on the creation of the BST/AVL trees.                                   |
| **Light Sign**                                 | **Sinal de Luz**                                       | A structure present in a track, which indicates the state of said track (according to the color of the light).                                                                |
| **Line**                                       | **Linha**                                              | Physical route connecting two endpoints, composed of one or multiple line segments.                                                                                           |  
| **Line Segment**                               | **Segmento de Linha**                                  | Part of a railway line with specific physical characteristics (gauge, maximum weight, speed limit).                                                                           |  
| **Loading Operation**                          | **Operação de Carregamento**                           | Operation of loading goods into wagons at terminals, depots, or industrial hubs.                                                                                              |  
| **Locomotive**                                 | **Locomotiva**                                         | Engine that pulls freight trains. Can be electric or diesel. Used in USLP03 travel time calculations.                                                                         |  
| **Locomotive Pilot/Engineer**                  | **Maquinista**                                         | Operator who drives trains, follows schedules, and ensures safe movement.                                                                                                     |
| **Longitude**                                  | **Longitude**                                          | A measure of distance west or east of the Earth's equator, expressed in angular degrees. It is used on the creation of the BST/AVL trees.                                     |
| **MVP (Minimum Viable Product)**               | **Produto Mínimo Viável (MVP)**                        | Minimum Viable Product to be developed iteratively and incrementally over the three sprints.                                                                                  |  
| **Order Lines**                                | **Linhas de Encomenda**                                | Individual lines of an order specifying SKU and quantity.Processed in USEI02 for allocation and USEI03 for picking plan generation.                                           |  
| **Parking Lines**                              | **Linhas de Estacionamento**                           | Sidings where wagons wait temporarily before being sent to another destination.                                                                                               |  
| **Partial Allocation**                         | **Alocação Parcial**                                   | Situation in USEI02 where only part of the requested quantity in an order line can be allocated from available inventory.                                                     |  
| **Path**                                       | **Caminho**                                            | Specific sequence of stations and line segments a train follows from origin to destination, manually defined by Freight Manager in USLP07.                                    |  
| **Perishable Goods**                           | **Produtos Perecíveis**                                | Goods with expiry date that require FEFO management.                                                                                                                          |  
| **Pick Path Sequencing**                       | **Sequenciamento de Rota de Recolha**                  | Sequencing of the product collection route in the warehouse to minimize distance traveled. Used during the process of USEI04.                                                 |  
| **Picker**                                     | **Operador de Recolha**                                | Operator who collects products from the warehouse following the picking plan generated in USEI03.                                                                             |  
| **Picking**                                    | **Recolha**                                            | Process of collecting products from one or more points in the warehouse to satisfy orders. Its organized in trolley batches in USEI03 and sequenced for efficiency in USEI04. |  
| **Picking Plan**                               | **Plano de Recolha**                                   | Output of USEI03 that specifies which products to collect, from which bays, in what order and quantity.                                                                       |  
| **Priority**                                   | **Prioridade**                                         | Priority assigned to an order that determines processing order in USEI02 allocation.                                                                                          |  
| **Quarantine**                                 | **Quarentena**                                         | Temporary state in USEI05 where returned products are placed before they can be reinserted into inventory, awaiting inspection.                                               |  
| **Quality Operator**                           | **Operador de Qualidade**                              | Operator (user role in USEI05) responsible for inspecting products in quarantine.                                                                                             |  
| **Rail Freight Transport**                     | **Transporte Ferroviário de Carga**                    | Network of trains, rails, terminals, and supporting infrastructure dedicated to freight transportation.                                                                       |  
| **Railway Infrastructure**                     | **Infraestrutura Ferroviária**                         | Includes tracks, stations, bridges, and tunnels that support the railway system.                                                                                              |  
| **Railway Terminal**                           | **Terminal Ferroviário**                               | Complex logistics node where freight wagons arrive and must be processed.                                                                                                     |  
| **Refrigerated Car**                           | **Vagão Refrigerado**                                  | Refrigerated wagon for transporting perishable goods.                                                                                                                         |  
| **Relocation**                                 | **Relocalização**                                      | Warehouse operation in USEI01 that updates a box's location (warehouse/aisle/bay).                                                                                            |  
| **Restock**                                    | **Reintegração**                                       | Action in USEI05 of placing products back into inventory after successful inspection.                                                                                         |  
| **Returns**                                    | **Devoluções**                                         | Products that return to the warehouse in USEI05 for various reasons (remorse, damaged, expired, cycle count).                                                                 |  
| **Rolling Stock**                              | **Material Circulante**                                | All vehicles that move and use the railway infrastructure (locomotives, trains, wagons).                                                                                      |  
| **Route**                                      | **Rota**                                               | Complete train journey plan in USLP07. Can be simple (single freight) or complex (multiple freight transported).                                                              |
| **Sensor**                                     | **Sensor**                                             | A device which detects or measures a physical property and records, indicates, or otherwise responds to it.                                                                   |
| **Scheduled Route**                            | **Rota Planeada**                                      | A type of route that contains a start and end time, which can be associated with a certain train.                                                                             |
| **Scheduler/Planner**                          | **Planificador de Horários**                           | User role responsible for analyzing, designing, and adjusting train timetables in USLP07 to maximize efficiency.                                                              |  
| **Siding**                                     | **Desvio**                                             | Designated area where trains must cross on single-track line, critical for USLP07 route scheduling.                                                                           |  
| **Single Track**                               | **Linha Simples**                                      | Line with a single rail where trains must cross at stations or sidings. Affects travel time and crossing operations in USLP07 scheduler.                                      |  
| **SKU (Stock Keeping Unit)**                   | **Unidade de Manutenção de Stock (SKU)**               | Stock Keeping Unit that uniquely identifies a product.                                                                                                                        |
| **Spacial Index**                              | **Index Espacial**                                     | A data structure used by spatial databases to quickly find geographic data without scanning every record.                                                                     |
| **Station**                                    | **Estação**                                            | Point in the railway network where trains can stop for loading/unloading operations.                                                                                          |  
| **Station Master**                             | **Chefe de Estação**                                   | Supervisor of station operations, coordinates arrivals and departures.                                                                                                        |
| **Station Storage Manager**                    | **Gestor de Armazenamento da Estação**                 | User role in USLP02 responsible for accessing terminal and managing cargo handling operations from ESINF Sprint 1.                                                            |  
| **Strategy A (Ascending/Deterministic Sweep)** | **Estratégia A (Varredura Ascendente/Determinística)** | Sequencing strategy that orders bays by ascending aisle, used in USEI04.                                                                                                      |  
| **Strategy B (Nearest-Neighbour)**             | **Estratégia B (Vizinho Mais Próximo)**                | Greedy strategy in USEI04 that always chooses the next nearest bay using 2D distance.                                                                                         |
| **Synoptic Board**                             | **Quadro Sinóptico**                                   | A display or interface that provides a comprehensive, at-a-glance summary of the current status of a system or situation.                                                     |
| **System administrator**                       | **Administrador de Sistema**                           | Manages the station configuration as well as the station master's data.                                                                                                       |
| **Tank Car**                                   | **Vagão Tanque**                                       | Wagon for transporting liquids, chemicals, and fuels. Can be Chemical Tank Car, Mineral Oil Car, or Pressure Gas Car.                                                         |  
| **Tare**                                       | **Tara**                                               | Weight of the empty wagon (without cargo).                                                                                                                                    |  
| **TDD (Test-Driven Development)**              | **Desenvolvimento Orientado a Testes (TDD)**           | Development approach where tests are written before implementation.                                                                                                           |  
| **Terminal**                                   | **Terminal**                                           | Facility for loading, unloading, and managing rail freight.                                                                                                                   |
| **Temperature Sensor**                         | **Sensor de Temperatura**                              | A sensor that measures the temperature of the place in which it is installed.                                                                                                 |
| **Time Zone**                                  | **Fuso Horário**                                       | An area which observes a uniform standard time for legal, commercial and social purposes. It can be seen in ESINF Sprint 2 user stories.                                      |
| **Train**                                      | **Comboio**                                            | A type of rolling stock, which uses one or multiple locomotives, used to run a scheduled route. They are used in the USLP07 scheduler.                                        |
| **Train Operator (Operating Company)**         | **Operador Ferroviário (Empresa Operadora)**           | Company that owns the rolling stock and operates railway services.                                                                                                            |  
| **Trolley**                                    | **Carrinho**                                           | Equipment used in USEI03, in which pickers collect items, with limited weight capacity.                                                                                       |  
| **Tunnels**                                    | **Túneis**                                             | Engineering elements that support freight movement through natural obstacles.                                                                                                 |  
| **UNDISPATCHABLE**                             | **NÃO EXPEDÍVEL**                                      | State of an order line used in USEI02 that cannot be satisfied with current inventory.                                                                                        |  
| **Unloading Operation**                        | **Operação de Descarregamento**                        | Operation of unloading goods from wagons at terminals according to FEFO/FIFO rules in USEI01.                                                                                 |  
| **Wagon/Freight Car**                          | **Vagão**                                              | Wagon designed to transport specific types of goods.                                                                                                                          |  
| **Warehouse**                                  | **Armazém**                                            | Storage facility organized in aisles and bays.                                                                                                                                |  
| **Warehouse Management System (WMS)**          | **Sistema de Gestão de Armazém (WMS)**                 | System implemented in ESINF Sprint 1 that meticulously records all goods movements in the warehouse.                                                                          |  
| **Warehouse Planner**                          | **Planificador de Armazém**                            | User role in USEI02 responsible for planning order fulfillment and inventory management.                                                                                      |  
| **Weight on Track**                            | **Peso nos Carris**                                    | Weight on the rails calculated as total weight divided by number of bogies. Must not exceed line segment maximum weight constraints in USLP07 route planning.                 |
